# Trip Planner

A modern travel planning web application built with React and Vite.

## Features

- Itinerary management
- Packing checklist
- Travel budget management
- Trip progress dashboard
- Real-time tracking
- Responsive UI

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/TripPlanner.git
```

Move into the project folder:

```bash
cd TripPlanner
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```
